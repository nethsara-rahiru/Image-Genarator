# Architecture

A single Node.js 22+ process (`node app.js`) serves the vanilla frontend and authenticated APIs on loopback. Caddy terminates public TLS; an SSH tunnel is the default alternative. Express sessions live in a bounded process-local store. DATA_DIR/admin.json stores only the administrator identity, Argon2id password hash and revocation version. A secure CLI creates/resets this identity; MongoDB and the old platform are not part of the rebuild.

RemoteBrowser owns one persistent Playwright Chromium context with at most eight tabs. Actions are serialized in a bounded promise queue. Each authenticated WebSocket gets state updates and JPEG frames with backpressure; input is mapped from the viewer canvas to the fixed 1280×800 viewport. Screenshot failures during navigation preserve the stream. Clients reconnect automatically. Browser profile locking is provided by Chromium; one PM2 instance is required. Browser closure cancels transfers and saves the profile. Inactivity stops it; viewer disconnection allows reconnection until idle/session expiry. Sessions are checked before frames and credential version changes revoke connections.

Uploads are bounded buffers sent to the active page's recent file chooser; downloaded originals are copied to randomized server filenames and fetched through authenticated routes. Newest 100 completed files are retained. Stop/shutdown waits for action completion, closes Chromium and terminates viewer sockets. No image content analysis or third-party AI integration is involved.

API: GET /api/session for session/CSRF bootstrap; POST /api/login; POST /api/logout; GET /api/state; POST /api/action; POST /api/upload multipart field file; GET /api/downloads; GET/DELETE /api/downloads/:id; GET /api/health. All routes except session bootstrap and login require admin authentication. POST/DELETE require exact Origin and x-csrf-token. GET health requires authentication. WS /stream requires admin cookie and exact Origin/Host. It supports start/stop/newTab/selectTab/closeTab/navigate/back/forward/reload/click/scroll/text/key fixed messages only. No arbitrary evaluation endpoint exists.
